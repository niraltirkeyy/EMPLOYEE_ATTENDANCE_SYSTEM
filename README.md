
# Employee Attendance Management System

A Python-based Employee Attendance Management System
developed using Object-Oriented Programming (OOP)
and JSON for data storage.

## Features

- Add new employees
- Automatically generate employee IDs
- View registered employees
- Mark employee attendance
- Prevent duplicate attendance entries
- Monthly attendance calendar
- Individual employee attendance reports
- Calculate attendance percentage
- Store records using JSON

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- Datetime Module
- Calendar Module

## Requirements

- Python 3.x
- No external libraries required

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Run the following command:

   python main.py

4. Use the menu to manage employee attendance.

## Attendance Status

| Code | Meaning |
|------|---------|
| P | Present |
| A | Absent |
| L | Leave |
| - | Not Marked |

## Data Storage

Employee information and attendance records
are stored locally in JSON format using
attendance.txt.

The attendance data file is excluded from
GitHub for privacy.
